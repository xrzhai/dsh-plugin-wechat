# 安全边界

本插件把微信消息交给本机 DSH 执行。发送者白名单控制谁能发起请求；宿主的工具权限决定 Agent 能做什么。插件不是操作系统沙箱。

## 出站附件

实现见 `src/media/outbound.js` 的 `allowedMediaDirs`、`resolveAllowedPath` 和 `resolveOutboundMedia`。

- 默认允许工作目录和插件状态目录；显式配置的额外目录也会加入允许范围。扩大范围意味着其中的文件可能被发送。
- 使用解析后的真实路径与目录包含关系判断，拒绝 `..` 越界、跨盘越界及指向范围外的符号链接。路径前缀相同不等于属于该目录。
- 文件需存在、是普通文件、非空且不超过上传限制（默认 100 MiB）。发送前短暂等待文件大小稳定，降低上传未完成文件的概率。
- 上传失败或附件被拒绝时仍保留文字回复，并报告失败原因。微信附件经过微信服务及 CDN；本地存储不意味着传输不经过服务器。

这些检查不是针对恶意本地进程的原子文件隔离：检查和上传之间仍有时间窗口，文件大小稳定也不能证明写入已全部完成。不要把不应外发的目录加入允许范围。

## 调度其他会话

平行会话调度默认关闭，并单独检查发送者、目标会话、受保护会话及只读路径。授权与已知限制见 [平行会话调度](session-dispatcher.md)。

## 凭据与验证

账号凭据保存在本地状态目录，不应提交到仓库或附在 issue 中。自动测试使用隔离状态及假传输；通过测试不代表已验证真实微信送达或所有宿主版本。
