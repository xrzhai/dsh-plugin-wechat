# 安全边界

「微信账号」的有效允许名单决定谁可以向这台电脑发请求，宿主的工具和本机用户权限决定助理能做什么。首次自动认主登记的是第一位实际发来消息的联系人；扫码后请用自己的微信先发消息，并核对登记结果。主人默认不受消息频率限制。频率限制不能代替身份校验。

## 出站附件

默认不按目录限制出站附件：无论是发送 `/send 文件路径`，还是助理在回复里给出文件路径，都可以发送本机进程能读取的普通文件，包括工作目录以外的文件。因此，只应授权你信任的人使用这个账号。相对路径先从会话工作目录查找，再查插件状态目录。需要限制发送范围时，可在插件配置的 `allowedMediaDirs` 中填写允许的目录，保存后重启 DSH。

文件必须存在、非空且不超过上传大小限制（默认 100 MiB）。上传前会短暂等待大小稳定；这不能保证其他程序已经完成写入。附件通过微信服务及 CDN 传输；本地保存凭据不意味着文件只停留在电脑上。

## 查看和指挥其他会话

此功能默认开启。当前账号所有获准对话的联系人，默认可以查看本机普通 DSH 会话的历史，也可以向可写会话派活、补充指令或请求停止。「高级 → 远程查看与管理 DSH 会话」可关闭该功能。若只想开放部分联系人或会话，用[调度配置](session-dispatcher.md)收窄范围。

当前来源会话、其他微信控制会话和内部子会话不开放给调度工具。归档会话、受保护会话和只读路径下的会话仅可查看。只读限制约束的是通过调度工具向会话发指令，不会改变文件权限，也不会隐去会话历史中的敏感信息。

## 凭据与验证

微信凭据保存在本地状态目录（默认 `~/.dsh/weixin/`），不要附在 issue 中。消息会由你选择的 DSH 模型和工具服务处理。自动测试使用隔离状态和模拟传输；真实微信送达和具体宿主版本的行为需单独验证。
