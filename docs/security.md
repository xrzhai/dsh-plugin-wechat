# 安全与权限说明

## 1. 谁能在微信里使唤这台电脑？

- **扫码后的自动认主**：新绑定一个微信账号且尚未配置允许名单时，插件会自动将**第一位给它发消息的联系人**登记为主人，并拒绝其他人的消息。因此扫码后请先用你自己的微信发一句“你好”或 `/status`。
- **允许名单管理**：你可以在「大肥鱼 → 微信账号」中查看当前已绑定的主人 ID，或按需添加其他你信任的微信联系人。主人默认不受消息频率限制。

## 2. 本机文件发送范围

- 默认情况下，只要是获准对话的联系人，无论是发 `/send 文件路径` 还是让助理在回复中附上路径，都可以发送本机当前用户可读的普通文件（不局限于默认工作目录，方便直接调取桌面或项目盘里的文档）。
- 单文件默认上限为 100 MiB。
- 如果你想把可发送的文件严格限制在特定目录内，可以在配置文件 `~/.dsh/weixin/config.json` 中设置 `allowedMediaDirs`（填入允许的目录路径数组），保存后重启 DSH 生效。

## 3. 跨会话查看与调度

- 获准对话的联系人默认可以列出、查询并指挥本机的其他普通 DSH 会话。
- 如果只想把微信当成独立聊天窗口，可以在「大肥鱼 → 高级 → 远程查看与管理 DSH 会话」中一键关闭。
- 已归档会话仅支持只读查看；当前微信控制会话自身以及内部子智能体不会被跨会话工具重复递归调用。

## 4. 本地凭据

- 微信登录态、会话映射与待发队列均保存在本机 `~/.dsh/weixin/` 目录下，切勿将该目录或其中的凭据文件上传至公开仓库或贴入 GitHub Issue。
