# 在微信里查看和管理其他 DSH 会话

出门在外时，你可以直接在微信里让大肥鱼帮你查看或操作电脑上正在跑的其他 DSH 会话，无需手动复制会话 ID：

- **找会话、看进度**：“帮我看看电脑上最近有哪些 DSH 会话，写周报那个跑到哪一步了？”
- **给空闲会话接着派活**：“让写周报那个会话把下周计划也补上。”
- **给正在跑的会话补充要求或喊停**：“让那个正在跑的会话顺便检查一下单元测试”、“让那个会话先停下来”。

---

## 一、默认行为与开关

- **开箱即用**：跨会话调度默认开启。只要是当前微信账号允许对话的联系人（包括首次发消息自动认主的主人），默认都能查看和调度本机的普通 DSH 会话。
- **一键关闭**：如果你不希望从微信操作其他桌面会话，打开「大肥鱼 → 高级 → 远程查看与管理 DSH 会话」，关闭总开关并保存即可。

---

## 二、进阶限制（按需配置）

绝大多数个人场景保持默认即可。如果你把微信账号开放给了其他协作者，希望限制谁能调度、能碰哪些会话或目录，可以编辑 `~/.dsh/weixin/config.json`：

```json
{
  "sessionDispatcherEnabled": true,
  "sessionDispatcherSenders": [],
  "sessionDispatcherTargets": [],
  "protectedSessions": [],
  "readOnlyPaths": []
}
```

- `sessionDispatcherSenders`：留空表示允许名单里的所有人都能用；填入特定微信 ID 后，仅列表内的人可调用跨会话工具。
- `sessionDispatcherTargets`：留空表示可管理本机所有普通 DSH 会话；非空时仅允许列出和操作名单内的会话 ID。
- `protectedSessions` / `readOnlyPaths`：填入的会话 ID 或工作目录路径仅允许在微信里只读查看进度，不允许发新指令或停止。已归档的会话同样默认为只读。

---

## 三、底层工具说明

插件为微信主会话注入了三个内置工具，助理会根据你的自然语言自动组合调用：

1. `session_list`：按状态（运行中 / 空闲 / 已归档）、标题关键词或工作目录筛选本机普通 DSH 会话。
2. `session_query`：读取目标会话最近 N 轮的对话摘要与工具执行状态。
3. `session_dispatch`：向目标会话发送后续任务（`followup`，仅限空闲会话）、运行中补充指令（`steer`）或停止请求（`cancel`）。若任务在等待窗口内未跑完，会自动转为后台跟进并在完成后把结果推回微信。
